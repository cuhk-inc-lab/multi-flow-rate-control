# UDP 最大链路容量：`10.20.20.11` → `10.20.20.12`

- 接口: `enp6s19` virtio 直连（非 VXLAN）
- 端口: 5212（干净 server）
- 原始: `build/iperf_10_20_20_udp_max_20260908-113430/`

## 结论

| 口径 | 容量 |
|---|---|
| **低丢包可用（loss ≲1%）** | **≈ 900 Mbps**（800M loss 0.36%；900M 0.91%；1G 已 1.57%） |
| **接收峰值（可接受高丢包）** | **≈ 1.94 Gbps**（offered 4G，loss ~25%） |
| 多流 -P4 峰值 | ≈ 1.78–1.89 Gbps（未明显超过单流峰值） |
| 对照同路径 TCP | ≈ 13 Gbps |
